# Goh Hui Min-site: personal portfolio
Plain HTML + Tailwind via CDN, with inline vanilla JS in `public/index.html`. No build step.
Deploy: push to main, GitHub Actions publishes `public/` to GitHub Pages.
Live: https://hm-base.github.io/Goh-Hui-Min-site/

## Conventions
- Site files live in `public/`. Main page is `public/index.html`; demo page is `public/sg-transit/index.html`.
- Section ids: #home #about #skills #experience #projects #contact.
- GitHub account is `hm-base`. LinkedIn: linkedin.com/in/hui-min-goh-01802ba3
- Resume download: `public/Hui_Min_Goh_Resume_83689592.pdf` (keep this exact filename).
- Never invent facts, metrics, employers, dates or titles; use [PLACEHOLDER] and ask.
- Keep it responsive; no horizontal scroll at 375px.
- Work on a branch; don't push straight to main.
